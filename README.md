## 课程修读与流程要点（学长实战经验）

### 1. 考察课属性与平时分考核
- 本课程为考察课，没有期末闭卷笔试，平时分占大头；
- **每周网课视频**：每周在学习通开放教学视频，必须按周刷完看满，视频观看进度直接计入平时分；
- **课前拍大屏幕签到**：每次上课前张艳老师会在大屏幕投影签到码或拍照要求，上课前必须准时拍照签到；
- **当堂练习下课前提交**：每节课前半段老师讲课，后半段自己动手做当堂 MATLAB 仿真内容，每节课下课前必须当堂在学习通提交，不能拖延；
- **随堂测验**：学习通不定期发起限时随堂测试。

### 2. 实验报告与大作业
- **个人实验报告**：期末需汇总提交整学期的上机实验报告；
- **大作业与翻转课堂**：
  - 期末以小组为单位选一个题目完成一份综合性大作业大报告；
  - 需制作 PPT 开展翻转课堂上台答辩讲解；
  - 本仓库收录了第 7 组大作业《基于 Super-twisting 与 ESO 的欠驱动船舶自抗扰控制仿真》的完整成果报告与全套 20 个 MATLAB 仿真算法源码。
