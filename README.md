## 课程简介与修读流程

本课程是自动化专业将控制理论（经典控制、现代控制）转化为计算机数值仿真与工程辅助设计（CAD）的核心上机课程。整个学期的上课节奏紧凑，通常在信工楼机房（如 333C）开展：

- **典型单堂课节奏**：前半节课张艳老师会结合课件讲解 MATLAB 仿真语法、控制系统建模、时频域分析函数或 Simulink 建模技巧；后半节课直接在机房电脑上现场编写、调试当堂指定的控制系统仿真模型。
- **考察课属性**：本门课虽为考察课，不设期末闭卷笔试，但**平时成绩权重极大**。平时的每一次签到、网课、课堂提交和随堂测验，都会直接拉开总评差距。

## 课程要求与踩坑指南（学长实战经验）

张艳老师对平时的流程规范和时间节点抓得很紧，以下 5 点是历届修读最容易丢分的“深水区”，务必高度重视：

### 1. 每周网课视频必须按时刷满
- 学习通上每周都会按进度开放线上网课视频。
- **务必按周刷完且进度看满 100%**。平时成绩后台系统会自动拉取网课观看进度与停留时长，不要想着最后突击，一旦被判定为未完成会直接扣减平时分。

### 2. 课前拍照签到严抓考勤
- 每次上课前，张老师都会在大屏幕投影上放出签到二维码或现场拍照要求。
- 必须准时到教室并在规定窗口内完成**现场拍照签到**。机房上课严禁旷课、代签或迟到，漏签对平时表现分影响很大。

### 3. 当堂练习下课前必须立即提交
- 每节课后半段布置的 MATLAB 仿真上机练习，**必须在当堂下课前在学习通完成提交**。
- 老师一般不下课后补交通道，手速慢或者没调通的容易超时。建议上课紧跟前半节的示例代码，后半节集中精力把仿真曲线跑出来及时截图保存。

### 4. 学习通不定期随堂测验
- 理论讲解和上机阶段，学习通会不定期发起限时随堂测试。
- 题目多为选择题与简答题，内容覆盖基础控制理论概念、MATLAB 核心函数指令（如 `tf`、`step`、`bode`、`rlocus` 等）与仿真基础知识，需留心听讲。

### 5. 期末大作业与翻转课堂答辩
- 期末以小组（通常 2 人/组）为单位开展大作业，分工完成系统建模、频域/时域特性分析、Simulink 建模仿真及综合实验大报告撰写。
- **翻转课堂答辩**：期末需制作汇报 PPT，小组上台开展翻转课堂汇报答辩，老师会针对建模机理、仿真框图与控制器抗扰性能进行现场提问。
- **第 7 组大作业范例**：选题为《基于 Super-twisting 与 ESO 的欠驱动船舶自抗扰控制仿真》，研究对象为 Nomoto 欠驱动船舶首向与航迹跟踪，设计了扩张状态观测器（ESO）和高阶超螺旋滑模控制器（Super-twisting），并与传统 PID 做了全方位阶跃、斜坡及频域鲁棒性对比。仓库内含完整的 20 个算法脚本、Simulink 自动构建代码与成果报告，可作为大作业设计与答辩汇报的完整参考范式。

## 考核方式总结

$$\text{总评成绩} = \text{平时成绩（网课进度 + 课堂签到 + 当堂练习提交 + 随堂测验）} + \text{期末大作业报告与翻转课堂答辩}$$
